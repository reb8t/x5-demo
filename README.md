# Пуш дома — тестовый билд

React + Vite + TypeScript. Дизайн — Figma «Альфа Юбиляры», страница «Диз» (секция 178:263).
Механика и математика — ГДД «Юбиляры»: https://docs.google.com/document/d/1ou7nhQEKkDQL2PtS4-d8vaEvoT9VpHI3cwVd0_km5ac

```bash
npm install
npm run dev        # игра — http://localhost:5173
```

Флоу выбираются кнопками в левом верхнем углу (или `?screen=game|sleep|rating|faq`, без параметра — онбординг).
Там же для теста механики: «+6 часов» (восстановление действий) и «Новый день» (подарок, параметры −5).

- `src/rules.ts` — правила по ГДД: прирост параметров, восстановление, очки, уровни Дружбы, формула Подарка.
  Пороги уровней Дружбы — заглушка, ждём таблицу с математикой.
- `src/App.tsx` — экраны и игровой флоу (онбординг, действия, листы, модалки, рейтинг, FAQ).
- `src/Push.tsx` + `src/engine/push.js` — живой Пуш на canvas: ролики с альфой, тень, переход «пуф» с вылетающими иконками/сердечками.
- `public/video` — ролики (WebM VP9 alpha для Chrome, MOV HEVC alpha для Safari). Готовятся вне репозитория пайплайном генераций.
- Шрифт Styrene A LC лицензионный и в репозиторий не входит — должен быть установлен в системе.

## Ветки

- `main` — то, что показываем клиенту.
- `dev` — текущая работа; фичи — в ветках от `dev`, слияние в `dev` через PR, в `main` — после проверки.
